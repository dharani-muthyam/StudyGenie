# StudyGenie – AI-Powered Study Assistant

StudyGenie is a Generative AI-based study assistant designed to help students learn more effectively. It uses AI to explain topics, summarize notes, generate quizzes, and answer study-related questions.

## Features

- 📚 Explain a Topic – Get simple explanations of difficult topics.
- 📝 Summarize Notes – Convert lengthy notes into concise summaries.
- 🧠 Generate Quiz – Generate multiple-choice questions with answers and explanations.
- 💬 Ask AI – Ask study-related questions and receive AI-generated responses.

## Technologies Used

- Python
- Streamlit
- Google GenAI API
- Gemma 4 31B IT
- python-dotenv
- Git & GitHub
- Visual Studio Code

## Installation

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install the required packages:

```bash
pip install -r requirements.txt
4. Create a .env file in the project folder and add your Google GenAI API key:
GEMINI_API_KEY=your_api_key_here
5. Run the Streamlit application:
python -m streamlit run app.py
6. Open the URL shown in the terminal to use StudyGenie.
